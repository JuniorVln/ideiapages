# Matriz de Nichos do MVP - Ideia Multi Chat

Data: 2026-05-07

Esta matriz lista os nichos candidatos para o primeiro ciclo estrategico do MVP. A prioridade abaixo e inicial, baseada em fit comercial, dores provaveis e conversa com Victor. Ela ainda nao substitui validacao por dados externos.

## Como ler esta matriz

**Fit com produto:** quanto o Ideia Multi Chat parece resolver dores reais do nicho.

**Intencao provavel:** chance de o nicho buscar ativamente solucao de atendimento, WhatsApp, CRM, chatbot ou organizacao operacional.

**Facilidade de pagina:** facilidade de criar uma landing page especifica sem parecer generica ou artificial.

**Prioridade inicial:**

- A: investigar primeiro e provavelmente incluir no lote inicial se houver demanda.
- B: investigar no primeiro ciclo, mas depende de dados externos.
- C: guardar para depois, salvo se os dados mostrarem uma oportunidade clara.

## Nichos de prioridade A para pesquisa inicial

1. Contabilidade.
2. Clinicas.
3. Odontologia.
4. Imobiliarias.

Esses nichos combinam dor clara, pagina facil de criar, potencial de conversao e uso natural de WhatsApp por equipes.

## Nichos de prioridade B para pesquisa inicial

1. Oficinas mecanicas.
2. Estetica.
3. Advocacia.
4. Escolas e cursos.
5. Assistencia tecnica.
6. Provedores de internet.
7. Seguros e corretoras.
8. Lojas e e-commerce.

Esses nichos devem entrar no primeiro levantamento de termos, mas so devem virar paginas do MVP se os dados externos mostrarem demanda ou SERP favoravel.

## Nichos de prioridade C

1. Concessionarias e revendas.
2. Academias.
3. Restaurantes e delivery.

Esses nichos ficam como reserva. Podem subir de prioridade se aparecerem em Search Console, Keyword Planner, concorrentes ou input comercial.

## Criterios para reavaliar a prioridade

A prioridade deve ser revisada depois da coleta externa usando estes criterios:

| Criterio | Pergunta |
|---|---|
| Demanda | Existem buscas reais para termos ligados ao nicho? |
| Intencao comercial | A pessoa parece procurar uma ferramenta ou apenas informacao? |
| Fit com produto | O Ideia Multi Chat resolve a dor sem depender de customizacao pesada? |
| Fit comercial | A Rede Ideia tem clientes, cases ou facilidade de venda nesse nicho? |
| Concorrencia | Os resultados atuais sao fortes ou ha brechas? |
| Especificidade | Da para criar uma pagina realmente especifica para o nicho? |
| Conteudo de apoio | Da para criar blog posts relevantes que sustentem a landing page? |

## Proximo uso desta matriz

No passo 3, cada nicho recebera uma matriz de termos baseada em padroes como:

- `sistema de atendimento para [nicho]`
- `whatsapp para [nicho]`
- `crm whatsapp para [nicho]`
- `chatbot whatsapp para [nicho]`
- `automacao whatsapp para [nicho]`
- `atendimento whatsapp para [nicho]`
- `plataforma de atendimento para [nicho]`

Depois, no passo 4, os termos serao validados com dados externos.
