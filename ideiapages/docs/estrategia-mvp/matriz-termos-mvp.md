# Matriz de Termos do MVP - Ideia Multi Chat

Data: 2026-05-07

Esta matriz define os termos-semente que serao validados na pesquisa externa. Ela ainda nao indica volume, dificuldade ou decisao final de paginas. O objetivo e estruturar a busca para descobrir como o mercado realmente procura uma solucao como o Ideia Multi Chat.

## Pergunta que este passo ajuda a responder

As pessoas procuram por uma solucao como o Ideia Multi Chat usando termos horizontais, termos por nicho, termos de dor ou termos ligados a concorrentes?

## Grupos de termos

| Grupo | O que investiga | Uso provavel |
|---|---|---|
| Horizontal | Busca pela categoria geral da solucao | Landing pages principais e paginas de dinheiro |
| Nicho | Busca por solucao aplicada a um segmento | Landing pages programaticas por vertical |
| Dor | Busca por problema operacional, sem nomear software | Blog, conteudo de apoio e links internos |
| Comparativo | Busca por alternativas, concorrentes e escolha de fornecedor | Paginas comparativas ou posts de alta intencao |

## Padroes por nicho

Cada nicho deve ser testado com estes padroes iniciais:

- `sistema de atendimento para [nicho]`
- `sistema de whatsapp para [nicho]`
- `whatsapp para [nicho]`
- `crm whatsapp para [nicho]`
- `chatbot whatsapp para [nicho]`
- `automacao whatsapp para [nicho]`
- `atendimento whatsapp para [nicho]`
- `plataforma de atendimento para [nicho]`

Quando o nicho tiver uma forma de busca mais natural, usar tambem variacoes. Exemplo: para contabilidade, testar `contadores`, `escritorio contabil` e `contabilidade`.

## Como validar no passo 4

Para cada termo, coletar:

- volume estimado;
- CPC ou sinal de valor comercial;
- tendencia;
- top 10 resultados da SERP;
- tipo de pagina que ranqueia;
- concorrentes recorrentes;
- presenca de anuncios;
- intencao dominante;
- oportunidade percebida;
- recomendacao: landing page, blog, comparativo, guardar ou descartar.
