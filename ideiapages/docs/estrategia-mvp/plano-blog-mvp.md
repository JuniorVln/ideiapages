# Passo 9 - Plano de blog para apoiar o MVP

## Objetivo

Usar o blog como camada de autoridade para apoiar as landing pages do MVP, sem dispersar a estratégia inicial.

O blog não deve começar como produção genérica de conteúdo. Ele deve funcionar como um mecanismo de apoio para:

- reforçar os temas que já apareceram com melhor sinal na pesquisa externa;
- criar links internos para as páginas principais do MVP;
- educar o mercado sobre dores que o Ideia Multi Chat resolve;
- sustentar a narrativa estratégica apresentada ao Victor;
- abrir espaço para testar novos nichos sem trocar a aposta principal cedo demais.

## Direção estratégica

A recomendação para o MVP é manter contabilidade como principal cluster vertical e incorporar imobiliárias como segundo cluster validado.

Essa decisão fica sustentada por três leituras:

- Contabilidade tem maior encaixe comercial conhecido pela base atual do produto.
- Contabilidade teve boa leitura de SERP em termos de intenção como "sistema de whatsapp para escritório contábil" e "atendimento whatsapp escritório contábil".
- Imobiliárias apareceram como o melhor nicho adicional na pesquisa externa, principalmente em termos ligados a atendimento, leads e automação.

Clínicas e odontologia devem ficar como observação estratégica para próximos testes. Há busca, mas a SERP mistura muito gestão clínica, agenda, prontuário e plataformas médicas, então a intenção ainda precisa de mais refinamento.

## Pilares de conteúdo

### Pilar 1 - Dor horizontal de atendimento

Conteúdos para capturar empresas que ainda não pesquisam por nicho, mas já sentem a dor operacional.

Exemplos de intenção:

- organizar atendimento whatsapp;
- centralizar atendimento whatsapp;
- controle de atendimento whatsapp;
- gestão de atendimento whatsapp;
- whatsapp com múltiplos atendentes.

Função no MVP:

- gerar autoridade geral;
- apoiar as páginas horizontais;
- servir como porta de entrada para empresas de qualquer segmento;
- conduzir para demonstração quando a dor estiver clara.

### Pilar 2 - Contabilidade

Conteúdos para aprofundar o principal cluster vertical.

Exemplos de intenção:

- sistema de whatsapp para escritório contábil;
- atendimento whatsapp escritório contábil;
- whatsapp para escritórios contábeis;
- automação whatsapp para contabilidade;
- chatbot whatsapp para contabilidade;
- crm whatsapp para contabilidade.

Função no MVP:

- reforçar a aposta principal;
- atacar o concorrente Zap Contábil com conteúdo de fundo e meio de funil;
- mostrar aplicação prática em fiscal, DP, financeiro, documentos, solicitações e SLA;
- aumentar autoridade das LPs de contabilidade.

### Pilar 3 - Imobiliárias

Conteúdos para validar o segundo nicho com melhor sinal externo.

Exemplos de intenção:

- atendimento whatsapp para imobiliárias;
- automação whatsapp para imobiliárias;
- sistema de atendimento para imobiliárias;
- sistema para atendimento de leads imobiliários;
- crm whatsapp para imobiliárias;
- whatsapp para corretores.

Função no MVP:

- abrir uma segunda frente vertical sem diluir a estratégia;
- testar demanda em mercado orientado a lead e velocidade de resposta;
- criar contraste com contabilidade na apresentação;
- medir se o produto performa fora da base atual.

### Pilar 4 - Comparativos e decisão

Conteúdos para serem usados depois da primeira onda.

Exemplos:

- melhor sistema de atendimento por whatsapp;
- plataforma de atendimento whatsapp;
- crm para whatsapp;
- chatbot ou atendimento humano no whatsapp;
- como escolher sistema de atendimento para whatsapp.

Função no MVP:

- ajudar usuários em fase de comparação;
- aumentar autoridade comercial;
- criar ponte para páginas de funcionalidades;
- não deve ser a primeira prioridade porque tende a ser mais competitivo e menos segmentado.

## Cadência sugerida para o MVP

### Semana 1

- Publicar os 2 blogs horizontais do top 10.
- Publicar 2 LPs de contabilidade.
- Publicar 1 LP horizontal.

### Semana 2

- Publicar 3 conteúdos de contabilidade.
- Publicar 1 LP de imobiliárias.
- Publicar 1 conteúdo de imobiliárias.

### Semana 3

- Publicar 2 conteúdos de imobiliárias.
- Publicar 2 conteúdos horizontais de apoio.
- Revisar Search Console para impressões, CTR e termos reais.

### Semana 4

- Ajustar títulos, metas e links internos com base no Search Console.
- Definir se clínicas/odontologia entram como nova rodada ou ficam para depois.
- Levar dados reais para o módulo de inteligência e autocura.

## Como apresentar ao Victor

Mensagem central:

"A estratégia não é criar blog por volume. É usar o blog para sustentar as páginas que queremos rankear, começando por contabilidade, que tem fit comercial e sinal de SERP, e incluindo imobiliárias como segundo nicho validado por pesquisa externa."

Pontos para destacar:

- O blog vira o indexador e apoiador da estratégia, como Victor sugeriu para a home/site principal.
- A primeira onda reforça as páginas que mais importam no MVP.
- A pesquisa de outros nichos será apresentada como slide adicional: imobiliárias entram agora, clínicas e odontologia ficam como observação para teste posterior.
- O Search Console deve virar a fonte de verdade depois da publicação, validando termos reais, páginas com impressão e oportunidades de ajuste.

## Critérios de sucesso

Para considerar o blog funcionando como apoio ao MVP:

- cada LP principal deve receber links de pelo menos 2 conteúdos de apoio;
- cada conteúdo deve apontar para uma página de conversão;
- cada cluster deve ter uma página principal e conteúdos satélites;
- o Search Console deve começar a mostrar impressões por termos de dor e nicho;
- os conteúdos com impressão e baixa CTR devem entrar na rotina de autocura.
